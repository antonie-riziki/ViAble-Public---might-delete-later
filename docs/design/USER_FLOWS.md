# Core user flows

## Understand a page

Open side panel → page context appears → choose Read or Summarise → ViAble announces current section → user can pause, stop, repeat, or ask a follow-up.

## Ask in mixed language

Type or speak a question → detect language and preserve original words → scope answer to active page → respond in selected language → offer text and audio controls.

## Form assistance

Choose Assist with form → show the action scope and privacy promise → require approval → explain required fields → fill only user-provided information → read back changes → keep submit separate and approval-gated.

## Recovery

If page changes, target is ambiguous, provider fails, or user interrupts: stop execution, describe what is known, keep the page unchanged when possible, and offer a clear next action.
