# ViAble design system

## Brand

Deep Navy `#0B1F33` is the structural foundation. Brand Teal `#087F70` is the primary action. Brand Green `#20C997` carries positive/voice energy. Brand Cyan `#16A6D9` marks information and interaction. Background `#F7FAFC`, Surface `#FFFFFF`, Secondary Text `#526579`, Border `#DCE5EC`, Error `#B42318`, Warning `#A15C00`, and Success `#087A50` complete the semantic palette.

Primary typography is Inter with Atkinson Hyperlegible and system fallbacks. The UI uses visible focus rings, minimum 44px primary controls where practical, high contrast, reduced motion support, and non-color status cues.

## Components

The first side-panel slice establishes reusable patterns for navigation, context cards, quick actions, voice orb states, status pills, conversation messages, playback controls, form approval dialogs, settings rows, privacy callouts, and toast announcements.

## Voice state language

Idle: “Ready to help.” Listening: “Listening.” Processing: “Thinking.” Responding: “Speaking.” Paused: “Paused.” Confirmation: “Your approval needed.” Every state has a visible label and a live-region status; voice is never the only route.
