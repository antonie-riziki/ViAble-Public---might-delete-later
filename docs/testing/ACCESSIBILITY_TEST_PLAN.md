# Accessibility test plan

- Keyboard-only: every navigation item, quick action, composer control, dialog, and settings control is reachable and has a visible focus state.
- Screen reader: headings, landmarks, button names, live status transitions, error states, and dialog focus are announced meaningfully.
- Visual: WCAG 2.2 AA contrast review, 200% zoom, text scaling, high-contrast treatment, and no information conveyed by color alone.
- Interaction: voice has text equivalents; listening can be stopped; confirmation can be accepted or declined without speech; reduced-motion preference is honored.
- Real assistive technology: validate with NVDA/VoiceOver on desktop and document TalkBack/Android work separately until an Android client exists.
